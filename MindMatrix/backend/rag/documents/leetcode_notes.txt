1. Two Sum (LeetCode 1)
==========================

Problem:

Find two numbers whose sum equals target.


Common Approach:

Brute Force:

Check every pair.

Time Complexity:

O(n²)


Optimal Approach:

Use HashMap.


Algorithm:

Store visited numbers.

For each number:

difference = target - number

Check if difference exists.



Time Complexity:

O(n)


Space Complexity:

O(n)



Pattern:

Hashing
