==========================
Arrays
==========================

An array stores elements in contiguous memory.

Common Operations:
- Traversal
- Searching
- Sorting
- Prefix Sum
- Sliding Window
- Two Pointer

Time Complexity:
Access : O(1)
Search : O(n)
Insert : O(n)
Delete : O(n)

---------------------------------------------------------

==========================
Hash Map
==========================

HashMap provides average O(1) lookup.

Used for:

- Two Sum
- Frequency Counting
- Duplicate Detection
- Group Anagrams
- Longest Consecutive Sequence

Advantages:

- Fast lookup
- Efficient searching
